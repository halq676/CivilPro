# 🏗️ CivilPro

**CivilPro** es una aplicación web diseñada para la gestión y cálculo preciso de materiales de construcción. Desarrollada pensando en la eficiencia en obra, permite a maestros y profesionales de la construcción obtener presupuestos rápidos de cemento, arena, hierro y ladrillo.

## 🚀 Funcionalidades
* **Cálculo de Muros:** Estimación de ladrillo (farol/sólido), cemento y arena según el área.
* **Módulo de Repello:** Cálculo optimizado de mezcla para acabados.
* **Estructuras de Concreto:** Cálculo de volumen para vigas y columnas, incluyendo acero de refuerzo (varillas y estribos).
* **Consolidado Automático:** Resumen total de materiales de múltiples elementos en una sola tabla.
* **Integración con WhatsApp:** Envío de pedidos de materiales directamente al proveedor con un solo clic.

## 🛠️ Tecnologías Utilizadas
* **HTML5 / CSS3:** Interfaz responsiva y amigable.
* **JavaScript (Vanilla):** Lógica de cálculo y manipulación del DOM.
* **Git/GitHub:** Control de versiones.

## 📱 Instalación y Uso
1. Clona el repositorio: `git clone https://github.com/halq676/CivilPro.git`
2. Abre `index.html` en tu navegador.
3. Ingresa las medidas de tu obra y genera el pedido.
